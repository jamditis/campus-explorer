# Texture credits

All tileable textures here are from [ambientCG](https://ambientcg.com/), licensed CC0, resized to 512 px and brightness-normalised so the model's own base colours tint them: Asphalt026B, Concrete034, Bricks066, Grass004, Ground054, Plaster001, RoofingTiles006, PavingStones126A, Gravel022, WoodChips002, Granite002A, Metal032, Wood049, Bark007. The alpha channel holds each set's displacement map (or colour luminance where there is none), used for shading relief.

Normal maps (`*_n.webp`, 512 px) are the same ambientCG sets' NormalGL maps, CC0, for every category except stone and metal (their normal maps are flat).
